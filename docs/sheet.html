구글 연결 (처음 한 번)

피드백은 내 구글 계정의 시트에 저장돼요. 고객은 로그인 없이 링크로 들어와요.

  2. ② script.google.com → [새 프로젝트] → 내용을 지우고 붙여넣기 → 저장(⌘S)
  3. ③ [배포] → [새 배포] → 톱니바퀴에서 [웹 앱] → 실행: 나 · 액세스: 모든 사용자 → [배포]
  4. ④ 권한 창: 내 계정 → [고급] → [(안전하지 않은) 페이지로 이동] → [허용] (직접 만든 코드라서 나오는 안내예요)
  5. ⑤ 나온 웹 앱 URL(…/exec)을 아래에 붙여넣기

API 키 만들기: console.cloud.google.com → 새 프로젝트 → "Google Drive API" [사용] → [API 및 서비스 › 사용자 인증 정보] → [API 키] → 키 수정 › API 제한: Google Drive API만 → 저장. 키가 없으면 드라이브 기본 플레이어로 열리고 시간을 직접 적어요.

연결 비밀키 — 맥의 피드백 도구도 같은 곳에 연결하려면 이 키를 맥의 연결 설정에 넣어 주세요.
