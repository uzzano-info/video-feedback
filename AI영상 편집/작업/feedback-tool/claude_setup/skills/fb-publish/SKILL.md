# 검토용으로 올리기

## 지금 컨펌본 현황
!`python3 작업/feedback-tool/fb.py status`

## 절차
1. **올릴 파일 확인** — 방금 렌더한 결과 파일 경로. 검토 페이지는 mp4(H.264)·mov·webm만 재생된다. ProRes 등이면 H.264 mp4로 다시 렌더한다.
2. **이름(base) 정하기** — 같은 영상의 이전 버전이 위 현황에 있으면 그 이름을 그대로 쓴다 (버전 번호는 자동). 처음이면 짧고 알아보기 쉬운 한글/영문 이름 (예: `애플이벤트_쇼츠`). 공백 대신 `_`.
3. **올리기**
   ```
   python3 작업/feedback-tool/fb.py publish <렌더 파일> --base <이름> \
     --project <프로젝트 폴더 절대경로> --render "<다시 렌더할 때 쓸 명령 그대로>" \
     --output <렌더 결과 파일 경로> --note "<이번 버전에서 바뀐 점 한 줄>" [--fixes id,id]
   ```
   - `--project`·`--render`·`--output`은 **꼭** 적는다. 다음에 "피드백 반영해줘"를 받았을 때 어디를 고치고 어떻게 다시 렌더할지 이 기록으로 안다.
   - 피드백을 반영한 렌더면 `--fixes`에 반영한 피드백 id를 쉼표로.
   - 결과: `컨펌본/<이름>_vN.mp4` 로 복사되고 `작업/productions/<이름>.json`에 제작 정보가 쌓인다. 원본 렌더 파일은 그대로 둔다.
4. **검토 페이지 열기** — `python3 작업/feedback-tool/fb.py open <이름>_vN` (서버가 꺼져 있으면 켜고 브라우저를 연다).
5. **사용자에게 안내** (한국어, 2~3줄) — 새 버전 이름, 이번에 바뀐 점, "보면서 C로 피드백 남기고 끝나면 '피드백 반영해줘'라고 해 주세요".
