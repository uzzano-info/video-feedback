# 영상 피드백 도구 사용법

컨펌본을 보면서 고칠 곳에 메모를 남기면, Claude Code가 그 메모를 읽고 **다빈치 리졸브 타임라인(FCPXML)의 새 버전**을 만들어 줘요.
"몇 분 몇 초에 이거 바꿔줘"를 메모장에 적었다가 하나하나 말할 필요가 없어요.

- 검토 페이지는 내 맥에서만 열려요 (추가 설치 없음, 맥에 있는 python3만 써요). 인터넷은 구글 드라이브 영상·고객 피드백을 쓸 때만 필요해요.
- 고객사는 구글에 올린 고객용 페이지에서 피드백을 남길 수 있어요 → 5번
- `소스/`와 `컨펌본/` 파일은 **읽기만** 해요. 원래 타임라인 파일도 덮어쓰지 않고 항상 새 이름(`_v3`, `_v4` …)으로 저장해요.

---

## 1. 도구 켜기

**`작업/feedback-tool/피드백도구.command`** 를 더블클릭하세요. 브라우저에 검토 페이지가 열려요.

- 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면 → 파일을 **우클릭 ▸ 열기** 를 한 번 누르세요. 다음부터는 그냥 열려요.
- Claude Code까지 한 번에 켜고 싶으면 `AI영상 편집/시작하기.command` 를 더블클릭하세요 (검토 페이지 + Claude Code 설정 설치 + Claude Code 시작).
- 페이지 주소: `http://127.0.0.1:8765/` · 끄기: 터미널에서 `python3 작업/feedback-tool/fb.py stop` (켜 둬도 맥에 부담은 거의 없어요)

**준비할 것 — 이름 맞추기가 제일 중요해요**

| 폴더 | 넣을 파일 | 예 |
|---|---|---|
| `타임라인/` | 리졸브에서 내보낸 FCPXML | `intro_v2.fcpxml` |
| `컨펌본/` | 같은 타임라인을 렌더한 영상 | `intro_v2.mp4` |

- 영상과 FCPXML의 **이름(확장자 빼고)이 같아야** 서로 짝지어져요.
- 리졸브에서 내보내기: 타임라인 선택 ▸ **File ▸ Export ▸ Timeline…** ▸ 형식 **FCPXML 1.10** (또는 1.9)
- 렌더는 **타임라인 전체, 처음부터 끝까지**로 해 주세요. 그래야 영상의 1프레임 = 타임라인의 1프레임으로 정확히 맞아요.

## 2. 피드백 남기기

1. 왼쪽 위에서 영상을 고르고 재생해요.
2. 고칠 곳에서 멈추고 **`M`** → 종류를 고르고 → 메모를 쓰고 → **`Enter`** 로 저장.
3. 오른쪽 목록에 쌓여요. 항목을 누르면 그 장면으로 이동해요.

**단축키**

| 키 | 하는 일 |
|---|---|
| `Space` | 재생 / 멈춤 |
| `←` `→` | 1프레임 앞뒤로 |
| `Shift` + `←` `→` | 1초 앞뒤로 |
| `M` | 피드백 쓰기 (메모 칸으로 이동) |
| `Enter` | 저장 · 줄바꿈은 `Shift` + `Enter` |
| `I` / `O` | 구간 시작 / 구간 끝 (구간 피드백) |
| `D` | 화면에 그려서 위치 표시 |
| `Esc` | 쓰던 것 취소 |

**종류** — 컷 삭제 · 길이 조절 · 순서 변경 · 자막·텍스트 수정 · 클립 교체 · 기타

**잘 쓰는 요령** — Claude가 추측하지 않도록 구체적으로 써 주세요.
- 컷 삭제는 **`I`/`O`로 구간**을 잡으면 정확히 그만큼 잘라요.
- 길이 조절은 얼마나: "끝을 1초 줄여줘", "15프레임 늘려줘"
- 클립 교체는 파일명: "`소스/IMG_7474.MOV`로 바꿔줘" (메모 칸에 파일명을 치면 자동완성돼요)
- 자막은 바꿀 문장 그대로: `자막 → "정말 좋네요"`
- "좀 별로야"처럼 애매하면 Claude가 고치지 않고 **질문**으로 남겨요.

**시간 표시** — `00:00:12:15` = 0시 0분 12초 15프레임. 영상 시작이 `00:00:00:00` 이에요.
옆의 `TL 01:00:12:15` 는 리졸브 타임라인에서의 위치예요 (리졸브 타임라인은 보통 `01:00:00:00`에서 시작).

**저장** — 쓰는 즉시 자동 저장돼요. 메모 칸 아래에 `✓ 저장됨`이 보이면 된 거예요.
`⚠ 저장 실패`가 보이면 `다시 저장`을 누르세요. 쓰던 메모는 브라우저가 기억하고 있어서 사라지지 않아요.

## 3. 반영 요청하기

방법은 둘 중 편한 걸로.

- **버튼:** 검토 페이지 오른쪽 위 **🤖 Claude Code에게 반영 맡기기**. 진행 상황이 페이지에 실시간으로 보이고, 끝나면 맥 알림이 와요.
- **터미널의 Claude Code에서:** `/apply-feedback` 입력 (또는 "피드백 반영해줘"). 영상을 지정하려면 `/apply-feedback intro_v2`.

Claude Code가 하는 일
1. 대기 중인 피드백만 읽어요 (영상을 지정하지 않으면 가장 최근에 수정된 피드백 파일).
2. 영상 시간 → 타임라인 위치 → 그 자리의 클립을 찾아요.
3. 타임라인 사본을 고쳐 **새 버전**으로 저장해요 (`intro_v2.fcpxml` → `intro_v3.fcpxml`). 잘라낸 만큼 뒤 클립을 당겨서 빈틈·겹침이 없게 해요.
4. 검사해요: XML 문법, 빈틈·겹침, 줄어든 길이 = 잘라낸 길이, 소스 파일이 있는지.
5. 결과를 피드백에 적어요. 페이지를 새로고침하면 보여요.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| `대기` | 아직 반영 안 됨 | — |
| `반영됨 ✓` | 고쳤어요. 아래에 무엇을 바꿨는지와 `[새 파일 이름]` | 리졸브에서 확인 |
| `질문 ?` | 애매해서 Claude가 물어봤어요 | 메모를 고치고 `↺ 다시 요청` |
| `보류` | 이 방법으로는 못 해요 (이유가 적혀 있어요) | 리졸브에서 직접 하거나 메모를 고쳐 다시 요청 |

## 4. 리졸브로 가져오기

1. 리졸브 ▸ **File ▸ Import ▸ Timeline…** ▸ `타임라인/` 의 새 파일(예: `intro_v3.fcpxml`)을 선택해요.
2. 창이 뜨면 **"Automatically import source clips into media pool"** 을 켜 두세요. 원래 클립을 그대로 다시 연결해요.
3. 원래 타임라인은 그대로 남아 있어요. 새 타임라인이 마음에 안 들면 그냥 지우면 돼요.

### 리졸브에서 확인할 체크리스트

- [ ] 가져올 때 **오류나 "미디어 오프라인"(빨간 클립)** 이 없나요? → 있으면 소스 파일이 옮겨졌는지 확인
- [ ] 타임라인 **총 길이**가 Claude가 알려 준 길이와 같나요? (컷 삭제·길이 조절한 만큼 줄었나요?)
- [ ] 피드백한 **각 위치**에서: 잘린 곳이 정확한지, 잘린 자리에서 말이 끊기거나 튀지 않는지
- [ ] 잘린 자리 뒤 클립이 **빈틈 없이** 붙어 있나요? (타임라인을 확대해서 검은 틈 확인)
- [ ] **B롤·자막·배경음악**(위·아래 트랙)이 원래 붙어 있던 장면과 같이 움직였나요?
- [ ] 배경음악이 잘린 자리에서 **뚝 끊기지** 않나요? → 필요하면 리졸브에서 짧은 크로스페이드 추가
- [ ] 자막 수정: 글자가 바뀌었고 **글꼴·크기·위치**는 그대로인가요?
- [ ] 클립 교체: 새 클립의 **시작 지점**이 원하는 장면인가요?
- [ ] 색보정·효과·전환(트랜지션)이 그대로인가요? (전환이 걸린 곳은 Claude가 건드리지 않고 `보류`로 남겨요)
- [ ] 마지막으로 처음부터 끝까지 **한 번 재생**해 보기

확인이 끝나면 새 버전을 렌더해서 `컨펌본/intro_v3.mp4` 로 넣고, 다시 피드백 → 반영을 반복하면 돼요.

## 5. 구글 드라이브 영상 · 고객사 피드백

### 구글 드라이브 영상 불러오기
1. 드라이브에서 영상 우클릭 ▸ **공유** ▸ 일반 액세스를 **"링크가 있는 모든 사용자"** 로 바꾸고 ▸ **링크 복사**
2. 검토 페이지 위쪽 **＋ 드라이브 영상** ▸ 링크 붙여넣기 ▸ 영상 이름 ▸ **불러오기**
   - 이름을 타임라인 FCPXML과 같게 하면(예: `intro_v2`) 리졸브 반영까지 그대로 돼요.
   - 프레임레이트는 "자동"이면 같은 이름 FCPXML을 따라가요. FCPXML이 없으면 직접 골라 주세요.
3. 목록에 `☁ intro_v2` 로 나타나요. 파일을 저장하지 않고, 내 맥 도구가 드라이브에서 받아 오면서 바로 재생해요 (인터넷 필요).

### 웹에서 바로 쓰기 (설정·로그인 없음) — https://uzzano-info.github.io/video-feedback/
1. 페이지를 열고 **＋ 드라이브 영상**에 드라이브 공유 링크 · 이름 · 프레임레이트 → **불러오기**
2. **🔗 고객 링크**를 복사해 고객에게 보내요.
3. 고객은 드라이브 플레이어로 보면서 **시간**(플레이어 아래 시간, 예: `1:23`)을 적고, 종류·메모를 남겨요. **✏️ 그리기**로 화면에 표시도 할 수 있어요.
4. 고객이 다 남기면 **📤 피드백 보내기** → 나온 링크를 카톡 등으로 나에게 보내요.
5. 그 링크를 클릭하면 고객이 남긴 시간·메모·그림이 내 화면에 그대로 보여요 (여러 명이 보내면 목록에 모두 모여요).
6. Claude Code로 리졸브까지 고치려면 맥 검토 페이지의 **📥 고객 피드백 링크**에 같은 링크를 붙여넣으세요. 같은 드라이브 영상으로 들어가요.

- 피드백은 서버에 저장되지 않고, 각자의 브라우저와 링크 안에만 있어요.
- 구글이 다른 사이트의 드라이브 영상 직접 재생을 막아서, 웹 페이지에서는 1프레임 이동·화면 캡처가 안 돼요 (시간은 직접 적기).

### (선택) 구글 시트로 자동으로 받기
고객용 페이지는 **내 구글 계정**에 올라가요. 고객은 로그인 없이 링크만 열면 되고, 내 맥이 꺼져 있어도 피드백을 남길 수 있어요.
(Claude Code 버튼이 있는 내 검토 페이지는 계속 내 맥에서만 열려요.)

**처음 한 번 — 연결 (5분)**
1. 검토 페이지 **🌐 고객 링크** ▸ **① 코드 복사**
2. [script.google.com](https://script.google.com) ▸ **새 프로젝트** ▸ 있던 내용을 지우고 붙여넣기 ▸ 저장(⌘S)
3. 오른쪽 위 **배포 ▸ 새 배포** ▸ 톱니바퀴에서 **웹 앱**
4. 다음 사용자로 실행: **나** · 액세스 권한이 있는 사용자: **모든 사용자** ▸ **배포**
5. 권한 창: 내 계정 ▸ **고급** ▸ **(안전하지 않은) 페이지로 이동** ▸ **허용**
   (내가 만든 코드라 구글 검토를 안 받아서 나오는 안내예요. 이 코드는 시트 하나만 만들고 써요.)
6. 나온 **웹 앱 URL**(…/exec)을 검토 페이지 칸에 붙여넣고 **연결**

**선택 — 드라이브 API 키 (고객이 프레임 단위로 정확하게 남기게)**
구글이 다른 사이트에서 드라이브 영상을 바로 재생하는 걸 막아서, 키가 없으면 고객 페이지는 **드라이브 기본 플레이어 + 시간 직접 입력**으로 열려요.
키를 넣으면 내 검토 페이지처럼 정확한 타임코드·프레임 이동·화면 캡처가 돼요. 만드는 법은 🌐 고객 링크 ▸ 연결 설정 아래쪽에 단계별로 있어요 (Google Cloud ▸ Drive API 사용 ▸ API 키 ▸ Drive API로 제한).

**영상마다 — 링크 보내기**
1. 드라이브 영상을 고른 상태에서 **🌐 고객 링크** ▸ **고객 링크 만들기** → 링크가 복사돼요
2. 고객에게 카톡·메일로 보내요. 고객은 이름을 적고, 영상을 보며 `M` → 메모 → `Enter` (휴대폰은 버튼으로)
3. 고객 피드백은 검토 페이지를 열어 두면 **20초마다 자동으로** 들어와요 (`👤 김대리 (고객 피드백)` 표시). 바로 받으려면 **⬇ 지금 가져오기**
4. 반영하면 고객 페이지에도 `반영됨 ✓` 으로 보여요. 고객은 자기가 남긴 피드백을 반영 전까지 고치거나 지울 수 있어요.

- 피드백 원본은 구글 드라이브의 시트 **"영상 피드백 (고객사)"** 에도 쌓여요.
- Claude가 반영할 때 고객 피드백도 똑같이 처리해요. 애매한 요청은 `질문 ?` 으로 남기니, 고객에게 확인한 뒤 메모를 고쳐 `↺ 다시 요청` 하세요.

## 6. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 더블클릭해도 안 열려요 | 우클릭 ▸ 열기. 그래도 안 되면 터미널에서 `python3 --version` 이 나오는지 확인 (안 나오면 python3 설치가 필요해요 — 먼저 알려 주세요) |
| 영상 목록이 비어 있어요 | `컨펌본/` 에 mp4·mov·webm이 있는지 확인 |
| 시간이 타임라인과 안 맞아요 | 영상·FCPXML 이름이 같은지, 렌더를 타임라인 처음부터 했는지 확인. 페이지 위치 칸에 `TL` 이 안 보이면 짝을 못 찾은 거예요 |
| 저장 실패가 떠요 | `다시 저장`. 계속되면 `작업/feedback/` 폴더가 있는지, 디스크 공간 확인 |
| 드라이브 영상이 안 나와요 | 드라이브 공유가 "링크가 있는 모든 사용자"인지 확인. 회사 계정은 외부 공유가 막혀 있을 수 있어요 |
| 고객 링크 연결이 안 돼요 | 배포할 때 액세스 권한을 **모든 사용자**로 했는지 확인. 코드를 고쳤다면 **배포 ▸ 배포 관리 ▸ 수정 ▸ 새 버전**으로 다시 배포 |
| "이미 다른 피드백 도구와 연결돼 있어요" | Apps Script 편집기 위쪽 함수 목록에서 `resetConnection` 선택 ▸ ▶ 실행 ▸ 다시 연결 |
